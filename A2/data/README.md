# Dataset Instructions

The dataset file is not committed to this repository in accordance with the assignment guidelines (avoiding dataset files in Git history).

## Dataset Source
- **Dataset Name:** Concrete Compressive Strength Dataset
- **Repository:** UCI Machine Learning Repository (Dataset ID: 165)
- **Donor:** Prof. I-Cheng Yeh (Chung-Hua University)
- **Direct Link:** https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength
- **Mirror Link:** https://raw.githubusercontent.com/ncuongce/AI-Machine-Learning/master/Concrete_Data.csv

## How to Obtain and Run
The notebook `A2_notebook.ipynb` automatically downloads the dataset directly from the official public mirror upon execution.

If running offline:
1. Download `Concrete_Data.csv` from the UCI repository or mirror link above.
2. Place the file inside this `data/` directory: `A2/data/Concrete_Data.csv`.
3. The notebook will automatically detect the local file and proceed with training.
