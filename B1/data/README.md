# Dataset Instructions: Task B1 (EMSCAD Dataset)

## Overview
- **Dataset Name:** Employment Scam Aegean Dataset (EMSCAD) / Real or Fake Job Posting Prediction
- **Source:** Kaggle (`shivamb/real-or-fake-fake-jobposting-prediction`)
- **Reference:** Vidros, S., Kolias, C., Kambourakis, G., & Akoglu, L. (2017). "Automatic Detection of Online Recruitment Frauds: Characteristics, Methods, and a Public Dataset." *Future Internet*, 9(1), 6.
- **Records:** 17,880 postings
- **Target:** `fraudulent` (0 = Real: 17,014; 1 = Fraud: 866)

## Acquisition
In accordance with course assignment policy, large raw dataset files are not committed to Git. The dataset can be downloaded directly from:
- [Kaggle: Real or Fake Job Posting Prediction](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction)

Place `fake_job_postings.csv` in this directory (`B1/data/`) to re-run the notebook from scratch.
