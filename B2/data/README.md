# Dataset Instructions: Task B2 (Wine Enthusiast Dataset)

## Overview
- **Dataset Name:** Wine Reviews (WineEnthusiast)
- **Source:** Kaggle (`zynicide/wine-reviews`, file `winemag-data-130k-v2.csv`)
- **Reference:** Thoma, Z. (2017). "Wine Reviews: 130k wine reviews with varieties and other information." Kaggle.
- **Records:** 129,971 raw reviews (119,955 unique reviews after removing 10,016 exact duplicates)
- **Target:** `points` (Continuous critic rating from 80 to 100)

## Acquisition
In accordance with course assignment policy, large raw dataset files are not committed to Git. The dataset can be downloaded directly from:
- [Kaggle: Wine Reviews Dataset](https://www.kaggle.com/datasets/zynicide/wine-reviews)

Place `winemag-data-130k-v2.csv` in this directory (`B2/data/`) to re-run the notebook from scratch.
