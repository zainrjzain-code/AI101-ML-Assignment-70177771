# Dataset Instructions: Task A3 (Dry Bean Dataset)

## Overview
- **Dataset Name:** Dry Bean Dataset
- **Source:** UCI Machine Learning Repository (ID: 602)
- **Reference:** Koklu, M. and Ozkan, I.A. (2020). "Multiclass classification of dry beans using computer vision and machine learning techniques." *Computers and Electronics in Agriculture*, 174, 105507.
- **Records:** 13,611 samples
- **Features:** 16 continuous morphological and shape features
- **Target:** 7 dry bean varieties (`Dermason`, `Sira`, `Seker`, `Horoz`, `Cali`, `Barbunya`, `Bombay`)

## Acquisition
In accordance with course assignment policy, large raw dataset files are not committed to Git. The dataset can be downloaded directly from:
- [UCI Machine Learning Repository: Dry Bean Dataset](https://archive.ics.uci.edu/dataset/602/dry+bean+dataset)
- Or programmatically loaded using `ucimlrepo` or `openpyxl`/`pandas` reading `Dry_Bean_Dataset.xlsx` or `Dry_Bean_Dataset.csv`.

Place `Dry_Bean_Dataset.xlsx` or `Dry_Bean_Dataset.csv` in this directory (`A3/data/`) to re-run the notebook from scratch.
